## 📄 List of Programs (Simple Descriptions)

- **1_hello_world.py** → Prints “Hello, World!”
- **2_if_else.py** → Shows basic if-else conditions
- **3_arithmetic_operators.py** → Addition, subtraction, multiplication
- **4_division.py** → Integer and float division
- **5_loops_print_1_to_n.py** → Prints numbers from 1 to n
- **6_is_leap.py** → Checks if a year is a leap year
- **7_print_function_examples.py** → Prints numbers in a single line
- **running_sum.py** → Running sum of a list (LeetCode)
- **shuffle_array.py** → Shuffles array in x1,y1 format (LeetCode)
- **kids_with_candies.py** → Checks which kid can have the most candies
